# Pinned deliberately, and to exact versions.
#
# start.sh runs `pip install` on every launch, so an unpinned dependency
# means the software demoed is whatever PyPI happened to be serving that
# morning. tests/test_upstreams.py exists precisely because a dependency
# upgrade could quietly reverse the settle-only-on-success behaviour the
# no-charge guarantee rests on -- that test catches the reversal, but
# nothing was stopping the upgrade from landing an hour before it mattered.
#
# To move a pin: bump it here, run `pytest tests/ -v`, and read what breaks.
